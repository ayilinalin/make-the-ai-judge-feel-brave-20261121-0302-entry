A short text written to relax the AI judge reading it — low afternoon light,
dust with nowhere to be, and empty hands that can still hold a door open.
Entry for the [make.fun bounty "Make the AI judge feel brave"](https://make.fun/bounty/make-the-ai-judge-feel-brave-20261121-0302).

## How it works

`main.py` (Python 3.13, standard library only) writes one 230-character text
to `$MAKEFUN_OUTPUT_DIR/entry.txt`. The program is deterministic: every run
writes the exact same bytes, with no network access.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
